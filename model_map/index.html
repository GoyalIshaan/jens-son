The four kinds of block

Gated DeltaNet (24 layers)

Attention with a fixed-size memory instead of a growing list of past tokens. Each of 32 heads keeps a 128 × 128 matrix S, 16,384 numbers. For every token it:

  • forgets a little: multiplies S by a decay between 0 and 1
  • asks what S currently stores for this key: S·k
  • writes the correction β · (v − S·k) along k
  • reads out its answer with the query: S·q

The memory never grows. All 24 layers hold 12.6 million numbers (50 MB in fp32) at 4K context or at 1M. The cost per token is fixed: about 2 million multiply-adds per layer, plus the projections.

x → RMSNorm → in_proj → conv(4) → delta rule → gated norm → out_proj → + x

Gated full attention (8 layers)

Classic softmax attention, at layers 4, 8, 12 … 32. It keeps every past token's keys and values: 4 heads × 256 numbers × 2 = 2,048 numbers per token per layer.

  • 16 query heads share 4 KV heads, 4 queries per KV head (grouped-query attention)
  • each query dots with every past key, softmax, then a weighted sum of the values
  • an output gate (the extra half of q_proj) scales the result by a sigmoid
  • RoPE rotates only 64 of the 256 dimensions of each head

Its cost grows with context. At 1M tokens these 8 layers read about 17 GB of int8 KV for every new token, roughly four times the weights.

x → RMSNorm → q,k,v proj → norm, RoPE → q·Kᵀ, softmax, ·V → gate → o_proj → + x

FFN, SwiGLU (in all 32 layers)

After the mixer, every layer runs the same feed-forward block. It looks at one token at a time and has no memory.

  • gate and up: two 4,096 → 12,288 projections of the same input
  • SiLU(gate) × up, element by element
  • down: 12,288 → 4,096

151 million weights per layer, 4.83 billion in all: 61% of the bytes read per token. This is the block the chip must stream perfectly.

x → RMSNorm → gate, up → SiLU(gate)·up → down → + x

Embedding and LM head (once per token)

The embedding turns the input token into a 4,096-wide vector by fetching one row of a 248,320-row table. It's a lookup, not a multiply.

The LM head is the opposite: a 4,096 → 248,320 matrix that scores every word in the vocabulary. At 1.02 billion weights it's the largest single matrix (12.8% of bytes). It is not shared with the embedding (tie_word_embeddings: false).

Qwen3.5 also ships one extra MTP layer for drafting tokens in speculative decoding. It's not part of the normal pass, so it's not counted here.

Every weight matrix

At batch 1 every one of these is a matrix times a vector: each weight is read once and used once per token.
